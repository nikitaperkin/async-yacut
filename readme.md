# YaCut

YaCut — это сервис укорачивания ссылок, реализованный на фреймворке Flask.  
Проект позволяет связать длинную пользовательскую ссылку с короткой, которую предлагает пользователь или генерирует сам сервис.

## Описание сервиса

Назначение YaCut — ассоциировать длинную пользовательскую ссылку с короткой, которую предлагает сам пользователь или предоставляет сервис.

Возможности сервиса:
- генерация коротких ссылок и их связь с исходными длинными ссылками;
- переадресация на исходный адрес при обращении к короткой ссылке;
- загрузка файлов на Яндекс Диск с генерацией коротких ссылок для каждого файла.

## Пользовательский интерфейс

Пользовательский интерфейс сервиса представляет собой веб-страницу с формой.

На главной странице предусмотрены два поля для ввода:
- поле для исходной длинной ссылки;
- необязательное поле для пользовательского варианта короткой ссылки длиной до 16 символов.

Также в проекте есть отдельная страница `/files` для загрузки файлов на Яндекс Диск.

## API

Сервис обслуживает два эндпоинта:
- `POST /api/id/` — создание новой короткой ссылки;
- `GET /api/id/<short_id>/` — получение оригинальной ссылки по указанному короткому идентификатору.

## База данных

В проекте настроено подключение к базе данных через ORM SQLAlchemy, а миграции выполняются с помощью Alembic.

## Как запустить проект

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/nikitaperkin/yacut.git
cd yacut
```

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
```

Если у вас Linux/macOS:

```bash
source venv/bin/activate
```

Если у вас Windows:

```bash
source venv/Scripts/activate
```

Установите зависимости:

```bash
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```

Создайте в корне проекта файл `.env` и добавьте переменные окружения:

```env
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key
DATABASE_URI=sqlite:///db.sqlite3
DISK_TOKEN=your_yandex_disk_token
```

Примените миграции:

```bash
flask db upgrade
```

Запустите проект:

```bash
flask run
```

## Доступные адреса

После запуска сервера приложение будет доступно по адресам:

- `http://127.0.0.1:5000/` — главная страница;
- `http://127.0.0.1:5000/files` — загрузка файлов;
